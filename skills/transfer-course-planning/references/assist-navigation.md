# How to Navigate assist.org for Articulation Agreements

## Two ways to get an agreement

If browser automation tools are available and working, use them to navigate assist.org and extract the agreement directly from the rendered page. This is the preferred path when possible.

If browser tools are unavailable or unreliable, ask the user to open the specific major's agreement on assist.org, use the page's print or PDF button to capture the content, and paste the text into the chat. The parser needs only the section headers and course rows.

## Why not a plain fetch

assist.org is a single-page application. Its JSON endpoints at `https://assist.org/api/...` return HTTP 400 to unauthenticated plain fetches—including WebFetch. The agreement data is only available in the rendered page that the browser JavaScript constructs. You must drive a real browser to get the content.

## The rendered-agreement URL

Agreement pages follow this URL pattern:

```
https://assist.org/transfer/results?year=<yearKey>&institution=<ccId>&agreement=<uniId>&agreementType=to&view=agreement&viewBy=major&viewSendingAgreements=false&viewByKey=<major-guid-path>
```

- `year` is an integer key that increments by one per academic year.
- `institution` is the sending community college's numeric ID.
- `agreement` is the receiving university's numeric ID.
- `viewByKey` is a GUID path generated by the site when you click a major—you obtain it by navigating the UI, not by guessing.

## Finding institution and agreement IDs

From the assist.org homepage form:

1. Select the Academic Year.
2. Choose the Institution (the community college).
3. Select "Agreements with Other Institutions" (the university).
4. Click "View Agreements".

In browser automation, the comboboxes are finicky: click the field directly, type the institution or university name, then click the matching option from the dropdown before moving on. Do not tab away without selecting from the dropdown.

The resulting results URL contains `agreement=<id>`—reuse that ID for any further lookups against the same university.

## Selecting the major

On the results page, switch to the "Major" view. Type the major name into the filter box and click the exact matching entry. Majors are often split by degree type (B.A. / B.S.) or concentration—select the one the student named. If unsure which variant applies, pull more than one and compare them.

## The "newest year is missing" trap

For many community-college to university pairs, assist.org has no agreement published for the newest academic year. The site silently serves the prior year instead, with only a small "not available" note visible. Always record which catalog year you actually retrieved and surface that year in your planner output to the student.

## Reading the agreement

The agreement displays in two columns:

- **Left column:** the receiving (university) course.
- **Right column:** the articulated community-college course, or the literal text "No Course Articulated".

Watch for these notes and apply them:

- "This course must be taken at the university after transfer" and "Course(s) must be taken at university" → no community-college option available; list this course on the student's after-transfer list.
- "Same as X" → the course is cross-listed under another prefix.
- "effective next fall, this articulation will be revised" → treat as provisional; advise the student to re-check before relying on it.

## Campus-specific general education

When a university uses its own lower-division general education instead of Cal-GETC, pull its "General Education / Breadth" agreement from the same results page (available as a separate view option). Include this alongside the major agreement.

## Paste fallback instructions

If you are directing the user to paste the agreement text, provide these instructions:

> Open the specific major's agreement on assist.org. Use the page's print or PDF button to capture all content. Paste the text here. I need the section headers and all course rows, including both the left (university) and right (community college) columns.
